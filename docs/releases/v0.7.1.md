Model setup and agent runs now route provider requests through TrueForge. This installer includes the eligibility fix that landed after v0.7.0, plus the latest command sandbox and dependency fixes.

## Changes

- Register OpenAI and OpenAI-compatible models through TrueForge. Model setup does not query the provider directly.
- Enter a custom model ID during setup. Saved credentials can restore the connection after an editor restart.
- Restrict command access to shared folders, service sockets, Apple Events, and application launch services.
- Update the bundled sandbox dependency to the patched Zod version.
- Build and test the packaged TrueForge connection before the release workflow publishes the installer.

## Install

1. Download `agentextension-0.7.1-darwin-arm64.vsix` from the release assets. This package supports Apple Silicon Macs.
2. In VS Code, run **Extensions: Install from VSIX** and select the file. Reload VS Code when prompted.
3. Open **AgentExtension → Connect model**. Paste your API key, or connect an existing local TrueForge server.

The installer includes Node.js and TrueForge. API keys are stored in VS Code SecretStorage. For another platform, follow the build instructions in the README.

## Verification

The release workflow runs the source checks and test suite, builds the VSIX, and tests the extracted installer with its bundled TrueForge server. The package test checks that model setup makes zero provider requests and that an agent run works after the saved connection is restored.

`SHA256SUMS.txt` contains the installer checksum.
