## Verification completed

- **Compaction reporting, 16 November 2026.** Forced a real compaction in TrueForge 0.184.2 and 0.185.1 with a scripted model and a VS Code host stub. The public event stream and session history supplied an event ID, a thread ID, trigger data, duration, and token usage. The pinned SDK 0.184.1 and published SDK 0.185.0 expose the same event fields. Retained source IDs remain unavailable. The test verified before-and-after source labels in the panel and the recorded counts, duration, and usage in the saved report. All 193 regression tests passed on the baseline runtime. [Compaction test](../test/compaction.test.js) · [TrueForge SDK event type](https://unpkg.com/@truefoundry/trueforge-sdk@0.185.0/dist/esm/api/types/ThreadContextCompactionFinishedEvent.d.mts)
- **Private memory sync, 16 November 2026.** The Notes panel syncs approved personal preferences for one enrolled user and workspace notes for that user within one project. The organization service requires an enrolled device credential and explicit opt-in. The editor previews incoming changes and asks before each sync. The tests used two checkout paths with separate credentials for the same user, plus a third project member, on one Mac. All five sync tests passed over loopback HTTP and trusted HTTPS. They covered account and project isolation, independent edits, concurrent changes and deletions, stale revisions, offline edits, lost responses, revoked access, and store limits. The full regression suite passed 191 tests. The hosted trial with two physical devices remains open. [Memory sync setup](../README.md#sync-personal-preferences-and-workspace-notes) · [Sync tests](../test/memory-sync.test.js)
- **Skill scripts and custom hooks, 16 November 2026.** The isolated runner supports standalone CommonJS files in interactive desktop VS Code. Each skill call requires approval for the exact script and input. The approved plugin digest pins each custom hook and its event. Tests on Apple silicon macOS and Debian 12 arm64 with bubblewrap 0.8.0 verified that the process could read its staged file and approved input. Attempts to read workspace or home files, write files, spawn a subprocess, or reach host loopback failed. Tests checked the five-second deadline and the combined 16,000-byte output cap. Cancellation stopped the child and removed temporary files. The macOS editor test used a VS Code host stub with real TrueForge and a scripted model. It verified the skill approval, scoped check data, cancelling validation, and a hook that blocked apply. All 186 macOS tests and ten targeted Linux runner and local MCP tests passed. [Skill script setup](../README.md#isolated-skill-scripts) · [Custom hook setup](../README.md#custom-plugin-hooks) · [Verification tests](../test/script-runner.test.js)
- **Local MCP, 16 November 2026.** A trusted workspace can enable a standalone Node.js server pinned by SHA-256 in VS Code user settings. Each interactive read requires fresh approval for the server, runtime, tool, target, and one string argument. On Apple silicon macOS and Debian 12 arm64 with bubblewrap 0.8.0, the fixture read its staged copy. Attempts to read workspace or home files, write a file, launch a subprocess, or reach loopback failed. Tests rejected unlisted tools, targets, and arguments. They invalidated approvals after file or policy changes and checked the output cap, cancellation, and the 15-second deadline. All 181 macOS tests and six Linux launcher tests passed. The macOS editor test used a VS Code host stub, real TrueForge, and a scripted model. It verified selection from user settings, the approval dialog, and the approved result. The VSIX build passed. [Local MCP setup](../README.md#local-mcp-over-stdio) · [Verification tests](../test/connector-local.test.js)
- **Background OAuth, 16 November 2026.** Each OAuth schedule requests a separate browser authorization for the verified connector account and scopes. The runner persisted rotated refresh tokens in owner-only storage without changing the approval. Tests refused a different account at enrollment and rejected a changed signed account, changed scopes, and an issuer-revoked grant during refresh. CLI revocation, account switching, and sign-out stopped local access and removed the credential. An in-flight refresh could neither restore the credential nor call the connector after revocation. The full suite passed 175 tests. All eight OAuth and background tests passed on Debian 12 arm64 with the runner from a fresh VSIX. The tests used a local OAuth issuer fixture. [Runner setup](../README.md#run-reports-with-vs-code-closed) · [Background integration tests](../test/background-live.test.js)
- **Linux background runner, 16 November 2026.** Built the VSIX in a Debian 12 arm64 container with Node.js 22.23.5. Both integration tests passed against the bundled runner with local TrueForge 0.184.2 and a scripted model. The fixture verified enrollment, one catch-up report with the simulated editor closed, history after reopening, a saved report despite an HTTP 503 webhook response, and credential removal and run denial after revocation. [Background integration tests](../test/background-live.test.js)
