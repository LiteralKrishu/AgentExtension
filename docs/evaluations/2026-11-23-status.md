# Agent comparison status

Date: 23 November 2026. This is a prerelease evidence inventory, not an independent product benchmark.

The development build adds strict completion scoring, fresh code retrieval, managed checks, scheduled coding drafts, draft handoff, and portable skill import. Implementation tests do not show Cursor or Codex parity. No local coding-model profile qualifies. Overall retrieval recall is 85.00%, below the 90% gate. The 87.50% held-out set was evaluated during the Claude handoff and is now exposed. It cannot serve as a new independent holdout.

No controlled Cursor or Codex corpus run was performed in this continuation. Their scores, costs, and completion rates are not available. Do not infer them from feature lists. API spending was zero. New runtime evidence uses scripted local responses, not a coding-model comparison.

## Fixed comparison procedure

1. Record the exact product version, installer hash, platform, model, model settings, runtime, corpus hash, and date.
2. Use the frozen [20-task corpus](../../test/model/corpus.json) and its independent acceptance checks. Start each attempt in a clean disposable repository.
3. Run three attempts per task. Preserve failed, cancelled, unavailable, and interrupted attempts. Do not replace them with successful retries.
4. Use each task's existing time, token, and tool budget. Record interaction and approval limits. If a product cannot expose a metric or honor a limit, report that restriction.
5. Use the same model only when each product supports it. Keep a same-model harness comparison separate from a comparison with each product's normal model.
6. Count only complete reviewed results that pass independent checks after disposable apply. Record first-attempt success, interventions, approval wait, active time, reported tokens and cost, and failure class.
7. Have a separate reviewer inspect the task labels and attempts before calling the comparison independent. Freeze a new hidden retrieval set before another holdout claim.

The [comparison ledger](../agent-capability-upgrade/evidence/comparison-2026-11-23.json) has one row per frozen task and marks all current product comparisons not run. Historical AgentExtension trials remain in the [evidence record](../agent-capability-upgrade/EVIDENCE.md); they do not become results for this changed build.
